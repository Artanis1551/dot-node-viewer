# ADR 0008: On-Demand Delegate Subgraph Expansion & Arm Ethos-U Command Stream Decoding

- **Status:** Accepted
- **Date:** 2026-10-24
- **Stage:** W01

---

## Context

Deployment formats for edge neural network execution (such as TensorFlow Lite and ExecuTorch) support hardware acceleration through **delegate execution blocks**:
- **TensorFlow Lite (`.tflite`):** The Arm Vela compiler lowers supported operator subgraphs into a single `CUSTOM` operator with `custom_code == "ethos-u"`. The operator payload is not stored in `custom_options`; rather, its input tensors contain a command stream tensor (`ethos_u_command_stream`, `uint8`), a flash tensor containing packed weights and scales (`read_only`), scratch arena tensors, and runtime activation IFMs. In addition, an `OfflineMemoryAllocation` metadata buffer maps arena tensor offsets.
- **ExecuTorch (`.pte`):** Models partitioned for Arm NPUs contain a `DelegateCall` instruction referencing backend `EthosUBackend`. The compiled payload in `BackendDelegate.processed` (exposed as `AttributeValue.Bytes(TensorDataSlice)`) contains a `vela_bin_stream` structured sequence of 16-byte-aligned named blocks (`vela_bin_stream`, `cmd_data`, `weight_data`, `scratch_size`, `inputs`, `outputs`, and `vela_end_stream`).

In both formats, the delegate appears in the top-level visual graph as a single opaque node (`CUSTOM(ethos-u)` or `Delegate (EthosUBackend)`). Machine learning practitioners and embedded systems engineers cannot inspect the actual operations generated by Vela (such as Conv2D, DepthwiseConv2D, Pooling, Elementwise, and DMA transfers), their tile shapes, memory address layouts, or driver configuration.

However, **ADR 0003** strictly prohibits eager decoding or buffer allocations of tensor weights and payload streams during `IModelFormatReader.ReadAsync`. Furthermore, the v1 Unified Graph IR contract (**ADR 0002**, **ADR 0006**) requires that IR records remain pure, immutable, and decoupled from UI or layout concerns.

---

## Decision

We introduce an **on-demand delegate subgraph expansion seam** in `DotNodeViewer.Core.Abstractions` and an Arm Ethos-U command stream decoder in `DotNodeViewer.Core.Delegates.EthosU`:

### 1. On-Demand Expansion Abstraction (`DotNodeViewer.Core.Abstractions`)
- Format readers (`TfliteFormatReader` and `ExecuTorchFormatReader`) do **not** eagerly decode command streams during `ReadAsync`. Instead, they tag eligible delegate nodes with standard attributes:
  - `delegate.backend = "ethos-u"`
  - `delegate.expandable = true`
- We introduce public abstractions for delegate decoding:
  ```csharp
  public interface IDelegateSubgraphExpander
  {
      bool CanExpand(ModelGraph graph, GraphNode node);
      ValueTask<Subgraph?> ExpandAsync(Stream modelStream, ModelGraph graph, GraphNode node, CancellationToken cancellationToken = default);
  }
  ```
- We introduce `DelegateSubgraphExpanderRegistry` (similar to `ModelFormatRegistry`) with `Default` pre-registering the Ethos-U expander, and thread-safe registration for future delegate decoders (e.g., XNNPACK or Qualcomm Hexagon).

### 2. IR Contract Additions
- **`TensorDataEncoding`:** Add `EthosUCompressedWeights = 2` (or `Opaque = 2`) to identify packed NPU weight and scale streams. When inspected, the weight inspector presents raw hex bytes rather than attempting numeric floating-point or integer decoding.
- **Operator Categories:** NPU operations map to existing semantic `OperatorCategory` enum values:
  - `NPU_OP_CONV`, `NPU_OP_DEPTHWISE` $\to$ `OperatorCategory.Layer`
  - `NPU_OP_POOL` $\to$ `OperatorCategory.Pooling`
  - `NPU_OP_ELEMENTWISE` $\to$ `OperatorCategory.Tensor` (or `Activation` for unary activation functions)
  - `NPU_OP_DMA_START` $\to$ `OperatorCategory.Data`
- **Subgraphs and Diagnostics:**
  - Expanded subgraphs are named `"{node.Name} ({targetArch})"` (e.g., `"ethos-u (Ethos-U55-128)"`).
  - Edge dataflow is inferred from memory addresses. To inform users, the expander attaches an informational `ParseDiagnostic` (`DiagnosticSeverity.Info`, code `DNV_ETHOSU_INFERRED_EDGES`): `"Decoded from NPU command stream — edges inferred from memory addresses"`.

### 3. Last-Writer-Wins Dataflow Edge Inference
Ethos-U operations access IFM and OFM feature maps via `(region, base_address, extent)` descriptors. Memory arenas frequently reuse buffers for successive non-overlapping activations.
- When an operation reads region $R$ in range $[addr, addr + extent)$, the edge connects to the most recent operation in command-stream order whose OFM wrote an overlapping address range in region $R$.
- Initial inputs are matched against `OfflineMemoryAllocation` offsets (TFLite) or `inputs` block descriptors (ExecuTorch) and mapped to `Subgraph.Inputs`. Final outputs are matched against `Subgraph.Outputs`.

### 4. Zero-Allocation Streaming Decoders (`DotNodeViewer.Core.Delegates.EthosU`, internal)
- `VelaBinStreamReader`: Validates 32-byte block headers (`16s I B 11s`) and slices named blocks (`cmd_data`, `weight_data`, `inputs`, `outputs`).
- `EthosUDriverPayloadReader`: Validates `"COP1"` magic, walks 32-bit Driver Action tags (`DACommands`), and extracts accelerator architecture configuration (`config_r`, `id_r`).
- `EthosUCommandStreamDecoder`: Zero-allocation `ref struct` over `ReadOnlySpan<byte>` decoding 32-bit `cmd0` (single-word) and `cmd1` (two-word) commands. Supports Ethos-U55, Ethos-U65, and Ethos-U85 command maps without heap allocations.
- `EthosURegisterState`: Mutable state machine updating register fields on `NPU_SET_*` and taking immutable snapshots upon each `NPU_OP_*`.
- Safety limits: Hard maximum of 4,194,304 command words and bounds checking against stream lengths. Corrupted payloads yield `ModelParseException` or `ParseDiagnostic` without crashing.

---

## Consequences

### Positive
- **Complete Visibility:** ML and firmware engineers can drill down into opaque delegate blocks and inspect synthesized NPU operations, register hyperparameters, and DMA transfers.
- **Zero Startup Overhead:** Graph parsing remains $O(1)$ with respect to delegate payload bytes. Command streams are decoded only when explicitly requested.
- **Extensible Architecture:** Adding decoders for other accelerators (XNNPACK, custom DSPs) follows the same `IDelegateSubgraphExpander` pattern without modifying format readers.

### Tradeoffs & Mitigations
- **Inferred Topology:** Hardware register streams do not encode explicit symbolic dataflow graphs. While last-writer-wins address matching faithfully represents actual memory traffic, an informational diagnostic clearly discloses that edges are inferred from memory addresses.
